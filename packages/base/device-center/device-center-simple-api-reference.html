附录：Schemas 数据模型字典

本附录详尽记录了所有由 HTTP Body 提交或响应接收的复杂大对象实体。对应于 Java 中位于 `pj/dto` 与 `pj/param` 下的类。

Pagination<T>通用分页返回体壳装
FieldTypeDescription
totalLong数据检索命中的总数量
pagesLong按照每页承载量切分出的总页面数
recordsList<T>当页剥离出的负载数据列表（泛型结果）
KeyValueWithTsDTO基础时序存取载体
FieldTypeDescription
keyString属性标识符代码
valueObject属性在当前时刻的值，可能是数值也可能是结构化文本
tsLong数据产生的时间戳 (毫秒)
DeviceTSDTO设备历史属性聚合包
FieldTypeDescription
deviceIdString设备归属ID
deviceNameString设备归属名称
deviceNumberString编号/序列号
propertyTsBoListList<PropertyTsDTO>包裹了针对单个属性的历史轨迹信息
DeviceSamplingTSDTO一次包含多属性刻面的采样数据
FieldTypeDescription
propValuesMap<String, KeyValueWithTsDTO>Map 形式组织的各个属性值快照
tsLong该采样点的时间基准
HistorySampleParam用于采样历史轨迹的条件约束
FieldTypeRequiredDescription
deviceIdStringTrue设备唯一识别
propertiesList<String>True要捕捉的属性字段群
startTsLongFalse采样的起始时钟区间
endTsLongFalse采样的结束时钟区间
stepIntegerFalse时间步长分片尺寸，单位为分钟（默认 1）
aggTypeStringFalse指定用于对步长内数据的聚合公式 (min, max, count, sum, avg, any, raw)
maxRecordsIntegerFalse结果防溢出限制，默认 1000
DevicePropParam设备单一控制或查询参量基类
FieldTypeRequiredDescription
deviceIdLongTrue指向设备的 Long 型主键
propertyCodesStringFalse过滤需要的 Code，以系统兼容的逗号做划分
notBeforeTsLongFalse不希望接收此时间之前陈旧数据的边界限定
